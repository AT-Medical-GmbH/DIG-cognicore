# Templates Directory

This directory contains reusable templates used across the **CogniCore™** platform and its
development workflows.

## Contents

| Subdirectory / File | Description |
|---|---|
| `github/` | GitHub issue and pull request templates |
| `emails/` | Transactional and notification email templates |
| `documents/` | Document and report templates (Markdown / DOCX) |

## Usage

Templates follow the AT Medical enterprise design language and must be reviewed by
`@AT-Medical-GmbH/platform-core` before modification.
