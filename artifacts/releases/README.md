# Artifacts – Releases

This directory stores release artifacts for CogniCore™.

**Contents:**
- Built distribution archives (`.tar.gz`, `.zip`)
- Release manifests
- Docker image manifests and digests

Artifacts are generated by the CI/CD pipeline and stored here for audit purposes.

> **Note:** Binary artifacts should not be committed to the repository directly.
> Use GitHub Releases or a dedicated artifact store for large files.
