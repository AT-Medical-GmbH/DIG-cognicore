## Guidelines

- All scripts must be written in **Bash** (`.sh`) or **Node.js** (`.mjs` / `.ts`).
- Include a usage comment block at the top of every script.
- Scripts must not contain hard-coded credentials or secrets.
- Use environment variables for all configurable values.
- Scripts must be idempotent where possible.

## Usage

```bash
# Example: run a script
bash scripts/your-script.sh
```
